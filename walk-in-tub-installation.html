Before Installation

Start with the right fit.

Walk-in tubs come in different sizes, door configurations and feature combinations. Before choosing one, the existing bathroom needs to be considered as a complete space.

Measure the existing bath

Length, width and surrounding wall space help determine which configurations may be suitable.

Consider room access

Hallways, doors and other access points can influence how a new tub reaches the bathroom.

Review existing utilities

Plumbing and electrical requirements depend on the selected tub and optional features.

What to Compare

Features that shape daily comfort.

Beyond overall dimensions, smaller design details can make a meaningful difference in how a walk-in tub feels and functions every day.

Entry Height

Compare threshold height and the space available for entering and leaving the tub.

Seating

Seat height, width and positioning affect comfort and ease of movement.

Door Style

Inward and outward opening doors can suit different bathroom layouts and preferences.

Controls

Controls should be positioned where they remain convenient to reach while seated.

Shower Options

Handheld shower accessories can make the bathing setup more flexible.

Built Around Your Space

Installation begins with planning.

A successful project considers the tub, the room, existing utilities and the everyday needs of the person using the space.

Installation Journey

From existing bath to walk-in tub.

The details vary by bathroom, but most projects involve the same core stages of planning and preparation.

Assess the bathroom

Existing dimensions, access points, plumbing and the current bathing area are reviewed.

Select the configuration

Tub dimensions, door direction and desired features are considered together.

Prepare the space

The existing bathing fixture may need to be removed before the new unit can be positioned.

Connect and finish

Necessary connections and surrounding finish details are completed for the new installation.

Everyday Details

Think beyond the bathtub.

A walk-in tub can be one part of a more comfortable bathroom. Placement of storage, flooring, lighting and frequently used items may also be worth considering.

  • Clear movement around the bathing area
  • Convenient towel and storage placement
  • Appropriate bathroom lighting
  • Easy-to-maintain surrounding surfaces

Installation FAQ

Before work gets started.

Useful questions to consider while planning a walk-in tub project.

Many walk-in tubs are designed with replacement projects in mind, but the available space still needs to be measured before deciding which configuration is appropriate.

For a typical replacement installation, the existing bath normally needs to be removed so the new walk-in tub can occupy the space.

Some additional features can have their own utility or electrical requirements, so they should be considered during project planning.

The new unit needs a practical route from outside the home to the bathroom, so entry doors, hallways and other tight spaces can matter.

It is generally useful to understand the bathroom constraints first, then compare tub configurations that can work with the available space and desired features.
